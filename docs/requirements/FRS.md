# Functional Requirements Specification (FRS) - Note Taking App

Baseline of the EXISTING application, derived from OpenSpec specs, code and tests (no new features proposed).

- Source specs: `openspec/specs/<capability>/spec.md` (cited as `spec:<capability>`).
- Code: `apps/api/src`, `packages/shared/src`, `apps/web/src`. Tests: `apps/api/src/**/*.test.ts` (API router tests run supertest against a real Prisma DB), `apps/web/src/**/*.test.tsx`, `apps/web/e2e/journey.spec.ts`.
- Test/code paths below are relative to `apps/api/src` unless prefixed with `apps/web` or `packages/shared`.
- Verification status: **VERIFIED** (an automated test asserts the criterion; file cited), **PARTIAL** (tested in part, or only at unit/mock level), **UNVERIFIED** (implemented, no test found), **MISSING** (expected by project docs/brief but not implemented).
